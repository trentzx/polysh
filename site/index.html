Get it

One small offline binary for Windows, macOS and Linux.

macOS / Linux
curl -fsSL https://raw.githubusercontent.com/trentzx/polysh/main/install.sh | sh
Windows (PowerShell)
irm https://raw.githubusercontent.com/trentzx/polysh/main/install.ps1 | iex
Homebrew
brew install trentzx/polysh/polysh
Scoop
scoop install https://raw.githubusercontent.com/trentzx/polysh/main/packaging/scoop/polysh.json

Teach your own shell

Keep your shell. polysh only steps in when you type a command it doesn't know.

zsh (~/.zshrc)
eval "$(polysh init zsh)"
bash (~/.bashrc)
eval "$(polysh init bash)"
PowerShell ($PROFILE)
Invoke-Expression (& polysh init powershell | Out-String)
fish (config.fish)
polysh init fish | source
